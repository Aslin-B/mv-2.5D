# Acueducto del Alba (proyecto 2.5D medieval)

Videojuego original de acción y exploración medieval 2.5D: personajes y escenarios 3D, movimiento y colisiones en un plano 2D.

La especificación de diseño vive en la biblia del proyecto (`2.5D_Medieval_v1.md`, carpeta compartida). Ruta técnica elegida: **A, Three.js + WebGL2**, empaquetado como HTML autónomo para navegador de escritorio.
